# 10. Gestão Ágil

## 10.1. Como o Projeto é Gerenciado (PI4)

Todo o acompanhamento é feito no GitHub, dentro do repositório:

| Elemento | Uso |
|---|---|
| **Milestones** | Cada milestone é uma sprint. Nome no formato "Sprint NN: Tema", com data de vencimento. |
| **Issues** | Tarefas soltas, do mesmo nível, agrupadas por milestone. Não se usam sub-issues. |
| **Project (Kanban)** | Quadro "Capital Injection: PI4", com as colunas **Backlog**, **Em andamento** e **Concluído**. |
| **Decisões de arquitetura** | Registradas como ADR em issue (ADR 001 = issue #88). |

Critério de tamanho das issues: abrangentes o suficiente para representar uma entrega, em quantidade enxuta por sprint.
